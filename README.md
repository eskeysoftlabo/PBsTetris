# PB's Tamriel de Tetris — 1.10.1 開発版

PS5のESO向け、石造りの落ちものパズルです。日本語UI、10列×20行の盤面（上部に内部判定用2行）、ホールド、次の3ブロック、着地点表示を実装しています。石の画像と雪の聖域の背景は本プロジェクト用に生成しました。ゲーム画面は全画面を覆い、盤面は縦横比を保って拡大します。

## 起動

- ソロ：ゲームパッドメインメニューの「ヘルプ」と「オプション」の間に追加される **ゲームセンターPX → タムリエル de テトリス**。
- 対戦：対象プレイヤーのインタラクトメニュー → **タムリエル de テトリス**。相手が承諾するとカウントダウン後に開始。
- 補助コマンド：`/pbt` はソロ画面、`/pbt debug` は通信とBGMの診断情報。

受信したパケットを弾いた場合も、理由を画面に表示します。招待が届いたのに受け付けられなかったときも同様です。以前はどちらも無言で捨てていたため、受け取った側では何も起きないように見えていました。通知は10秒に1回までに絞ります。

送信の可否と受信の可否は別の判定にしています。送信側では本体の通信許可（`CanCommunicateWith`）を確認しますが、受信側では確認しません。LibGroupBroadcastは同じグループ内にしか配送せず、やり取りしているのはプレイヤーが書いた文章ではなく盤面の数値で、この許可が両者で違う答えを返すと届いたものを全部捨てることになるためです。コンソールでは通信制限の設定によりこの許可が落ちることがあります。

招待が送れなかった場合は理由を画面に表示します。以前は無言で失敗していました。`/pbt debug` で通信ID・プロトコルの有効無効・グループ人数・自分の宛先識別子・送受信数（自分宛でなかった数、拒否した数、採用した数）・直近の失敗理由を確認できます。受信が0なら相手から届いていない、受信があるのに採用が0なら宛先か送信者判定で弾かれている、と切り分けられます。

対戦は両者に同じバージョンの本アドオンと **LibGroupBroadcast** が必要です。同じグループで、両者がオンラインかつ非戦闘状態のときに招待できます。ライブラリがない場合でもソロは遊べます。ソロを開いている間は対戦招待を受け付けません。

## 操作

画面下のESO標準ボタン表示に従ってください。決定／戻るのボタン割り当ては本体設定に従います。

| 操作 | 動作 |
| --- | --- |
| 方向キー 左・右 | 横移動。長押しで連続移動 |
| 方向キー 下 | ソフトドロップ。押した瞬間にまとめて落ちることはありません |
| 方向キー 上／画面下「一気に落とす」 | ハードドロップ |
| 決定／「右回転」 | 右回転。招待承諾・ソロ再開・再挑戦にも使用 |
| L1／「左回転」 | 左回転 |
| 「ホールド」 | ブロックを保持／交換。固定まで1回 |
| 戻る | ソロは一時停止、もう一度押すと閉じる。対戦中は降参して閉じる |

ソロを閉じた後は同じセッション内なら続きから再開します。自己ベスト得点と最大消去ライン数はアカウント共通で保存します。盤面自体はログアウトをまたいで保存しません。

## ルール

7種類が一巡するランダム方式とSRS回転補正、0.5秒の接地猶予を採用しています。ソロは10ライン消すごとにレベルが上がり、落下間隔が0.85秒から段階的に短くなります（レベル19までの最短0.055秒、レベル20から20G）。

1／2／3／4ライン同時消去の基本得点は100／300／500／800×現在レベル。ソフトドロップは1マス1点、ハードドロップは1マス2点。連続消去ボーナスと4ライン消去の継続ボーナスがあります。

対戦は同じ初期ブロック順です。1／2／3／4ライン消去で0／1／2／4段のおじゃまを送ります。連続消去で最大4段、4ライン消去継続で1段の追加攻撃があります。自分の攻撃は先に受信済みのおじゃまと相殺し、残りを相手へ送信します。受けた段は次にブロックを固定した際に下から追加されます。各段にはランダムな1マスの穴があります。

出現位置の衝突、上部の隠し行だけでの固定、またはおじゃまによる盤面外への押し出しで敗北します。両者の終了が通信上重なった場合は引き分けとして扱います。通信が15秒途切れたときは勝敗を付けず中止します。対戦中の画面終了・コントローラー切断は降参、グループ離脱・戦闘開始など通信条件を失った場合は中止します。対戦中の一時停止はありません。

対戦中は画面を左右に分けます。左半分が自分（盤面・ホールド・次のブロック・スコア）、右半分が相手です。相手の盤面そのものは送られてこないため、右半分には相手の積み上がり高さを自分の盤面と同じ縮尺のゲージで表示します。形は分かりませんが、高さは正確な値です。

相手の情報は高さ・おじゃま段数を表示します。相手の盤面全体は送信しません。Tスピン・パーフェクトクリア専用ボーナスは未実装です。通信は約1.5秒ごとの累積値で重複と取りこぼしを補正するため、攻撃反映には遅延があります。

## 20G

通常のソロ・対戦とも、自分のレベルが20（190ライン消去）に達すると20Gに移行します。すぐ遊ぶ場合は「ゲームセンターPX → タムリエル de テトリス（20G）」または `/pbt 20g` を使用してください。通常ソロと最初から20Gの自己ベストは別に保存します。進行中のソロから別モードを起動すると盤面は新規になります。

20Gでは出現時、ホールド交換時、横移動・回転の成功直後に接地位置まで落とします。自動落下によるドロップ得点は加算しません。接地から0.5秒で固定。移動・回転による猶予の延長は1ブロック15回までとし、無限に固定を先延ばしできないようにしています。ハードドロップはその場で即固定します。

ユーザー指定のTGMの20G動作を参考にした実装で、回転方式は本アドオンのSRSを継続しています。TGM固有のARS・IRS・段位・レベル曲線の完全再現ではありません。プレビューの「20G実演」は本体Luaエンジンの3秒間の動作記録を繰り返し表示します。ブラウザでの操作プレイではありません。

通信のフィールド構成を、コンソールでの動作実績があるPBsJankenと同じ形に揃えました。版に2ビット、種別に3ビット、残りはすべて32ビットです。以前は31・16・5・2ビットの狭いフィールドを混ぜており、これが動作実績のある実装との唯一の配線上の違いでした。攻撃段数・高さ・終了状態は1語にまとめて送ります。プロトコル名を `PBsTetrisV3Dev` へ更新したため、1.8.x以前とは対戦できません。

パケットの先頭に版番号とビルド番号を載せます。この2つは幅を変えないので、以降どこを変更しても、**相手が別のバージョンなら「相手のバージョンが違います（相手 11000 / 自分 10900）」と具体的に表示**できます。以前は相手が別バージョンだと、読めないデータを宛先違いとして捨てるだけで、招待が届かない原因が分かりませんでした。ビルド番号は `scripts/package.py` がマニフェストの `AddOnVersion` と一致しているか検査します。

自分が送ったパケットは、ライブラリから自分にも返ってきます。これは異常ではないので、PBsJankenと同様に無言で捨てます（1.9.0では送信側にこの折り返しを「弾きました」と表示してしまっていました）。

宛先が自分と一致しなかったパケットも、理由を画面に表示します。受信した宛先と自分の識別子を併記するので、食い違っていればその場で分かります。以前はこの経路だけが無言のままでした。

対戦のルールが変わるため、通信バージョンを2へ更新しました。対戦相手も1.10.1へ更新してください。旧版との混在対戦はできません。

## ライン消去の演出

ラインが揃うと、そのライン全体が左から右へ払われるように消えます。盤面の落下は消去と同時に確定しており、演出はUI側だけで行います。そのため描画が遅れても、得点・おじゃま・対戦の進行には影響しません。演出中のわずかな時間だけ、消える直前の盤面をそのまま表示します。

4ライン同時消去のときは色と長さが変わります。通常の消去は白で0.18秒、4ライン同時は金色で0.3秒です。効果音も4ライン同時だけ別（`SCRYING_CAPTURE_GOAL`）です。演出中は描画間隔を1/60秒へ上げます。

## 画面の切り替え

メニューや `/pbt` から開くと、いったん画面全体が暗転してから盤面が現れます。0.28秒かけて黒へ落とし、完全に黒くなった時点で盤面の表示を開始し、**盤面がシーンとして表示し終わるのを待ってから**0.34秒かけて明けます。暗転幕は専用の最上位ウィンドウで、`SetDrawTier(DT_HIGH)` によりゲームパッドメニューごと覆います。

幕を上げる合図には `SCENE_SHOWN` を使います。`SCENE_MANAGER:Show` は元の画面を閉じてから数フレームかけて新しい画面を立ち上げるため、`Show` の直後や `IsShowing()` を合図にすると、その隙間から通常のゲーム画面が一瞬見えます。シーンが立ち上がらなかった場合に画面が黒いままにならないよう、1.2秒の上限も設けています。

暗転中はゲームが進行しません。盤面の進行は画面が表示されていることを条件にしているため、幕が上がるまで最初のブロックは落ちません。暗転の最中に戦闘へ入る・コントローラーが外れるなどで開けなくなった場合は、盤面を出さずに幕だけが明けます。

対戦の招待を受けた側は暗転しません。通知として即座に出します。

## 盤面の演出

盤面が高くなるほど雪が強くなります。自分の積み上がり高さから雪片の数・落下速度・横揺れを決め、最大48片まで増やします。盤面が空でもわずかに降り、天井が近づくと吹雪きます。雪片は `assets/flake.dds` を個体ごとに大きさと不透明度を変えて使い回します。アニメーションタイムラインではなくフレームごとの移動で処理しています。数が数秒おきに変わるため、タイムラインを組み直す方が高くつくからです。

レベルが上がると、盤面の中央に「レベル 5」と金色で表示され、1.5秒かけて浮き上がりながら消えます。レベル20に到達したときは「レベル 20 · 20G」と出し、落下方式が変わることを知らせます。効果音はESO内蔵の `LEVEL_UP` です。

表示はエンジンが持っているレベルの変化から判断します。イベントではなくレベルそのものを見ているため、画面を閉じている間の昇格を取りこぼしたり、再挑戦でレベル1に戻ったときに誤って出したりしません。

ブロックには斜めの光沢が走ります。左下から右上へ1.5秒かけて通り、4.2秒周期で繰り返します。各マスの明るさは光の帯からの距離を5段階に量子化し、段階が変わったマスだけ色を設定し直します。毎フレーム200マスを塗り直すことはありません。ゴーストブロックと消去演出中のマスは光りません。

## 音楽と効果音

PS5アドオンではESO内蔵効果音を、移動・回転・ホールド・固定・ライン消去・レベルアップ・開始・勝敗に連動させています。長押しの音は間引きます。`/pbt sound` で効果音を切り替えられます。

BGMは公開API `SetOverrideMusicMode` で差し替えます。R1（画面下の「BGM：〜」）または `/pbt music` で、次の5種類を順に切り替えられます。選んだ曲はアカウント共通で保存します。

| 表示 | モード | 流れる曲 |
| --- | --- | --- |
| BGM：切 | `OVERRIDE_MUSIC_MODE_NONE` | 差し替えなし（そのゾーンのBGM） |
| BGM：カード | `OVERRIDE_MUSIC_MODE_TRIBUTE` | カードゲーム Tales of Tribute |
| BGM：星座 | `OVERRIDE_MUSIC_MODE_CHAMPION` | チャンピオンポイント画面 |
| BGM：決闘 | `OVERRIDE_MUSIC_MODE_DUELING` | 決闘 |
| BGM：終幕 | `OVERRIDE_MUSIC_MODE_CREDITS` | クレジット |

BGMの差し替えには `OVERRIDE_MUSIC_MODE_*` 定数を使いますが、これらは `rawget(_G,...)` では読み取れません。クライアントの定数は素の大域変数として置かれているとは限らず、素読みすると黙って `nil` になり、差し替えが起きないまま表示だけが切り替わります。名前で直接参照してください。`/pbt debug` が要求値・現在値・所有状態を出力します。

一時停止・画面終了時は、遊び始める前のモードへ復元します。他の処理が後からモードを変更していた場合は、上書きも復元もせず、その画面のあいだは差し替えを諦めます。ESO全体の音量設定は変更しません。

**独自アレンジ曲をPS5アドオンで再生する機能は実装できていません。** 現行の公開APIに任意の音声ファイルを再生する手段を確認できないためです。PS5ではESO標準BGMを使います。曲そのものは `audio/stone-and-snow-epic.mp3` とWAVで制作済みで、ブラウザプレビューの「BGMを聴く」から再生できます。

独自アレンジはロシア民謡「コロブチカ」の旋律に、低音弦・角笛風の音・太鼓と残響を加えた148 BPM・約62秒のシンセサイザー音源です。ゲーム作品の既存録音は使用していません。ブラウザの効果音は試聴用の合成音で、PS5の内蔵効果音とは異なります。

プレビューは `http://127.0.0.1:18770/preview/?v=1.10.1`。「没入表示」で操作パネルを隠して全画面化します。ブラウザによってはタブ内全画面になります。曲はユーザーの再生操作後に鳴り、一時停止・非表示で停止します。

## 配布物と開発

`dist/PBsTetris-1.10.1.zip` にインストール用 `PBsTetris/` を収録しています。`.addon` と `.txt` の両マニフェストに **assets/stone.dds と assets/sanctuary.dds を明記**しています。DDSファイルの同梱だけではPS5で読み込まれなかった過去の事例に対する再発防止です。

PS5本体でZIPを直接導入する手順を提供するものではありません。既存PBsシリーズと同じコンソール用アドオンのアップロード・テスト経路で使用してください。この作業では公開アップロードは行っていません。

```sh
cd /Users/kurokawasatoru/DevProject/ClaudeProject/PBsTetris
luajit tests/run.lua
python3 tests/check_package.py
python3 scripts/package.py --check
python3 scripts/package.py
```

素材再生成にはPillowを利用し、`python3 scripts/build_assets.py` で生成元PNGからDXT5・512角・全10段階のミップ付きDDSへ変換します。

**PS5実機では未検証**です。ローカルのLuaテストはゲーム処理とAPIの結線を検査し、ESOクライアントの動作を保証するものではありません。実機確認項目は [docs/PS5-CHECKLIST.md](docs/PS5-CHECKLIST.md) に記載しています。

通信の初期化に失敗した場合は、ログイン時に理由を画面に表示します。招待を受ける側は自分から招待しないため、以前はこの失敗に気づく手段がありませんでした。

`DeclareProtocol` は、そのIDまたは名前がすでに使われているときだけ失敗します。したがってこの失敗の原因は1つしかありません。**同じクライアント上の別のものがID 510を先に取得している**ことです。最も多いのは本アドオンが二重に導入されている場合です。ライブラリの元メッセージには先に取得している側のプロトコル名が入るので、そのまま表示します。

対戦プロトコルは開発用ID **510** を使用しています（Jankenの511とは別）。他アドオンと共有する正式なID予約は未完了です。一般公開前に[LibGroupBroadcastの管理表](https://wiki.esoui.com/LibGroupBroadcast_IDs)で予約し、必要に応じて `Transport.lua` のIDを更新してください。
