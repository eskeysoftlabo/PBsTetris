# PS5実機確認

現時点で全項目が実機未確認です。以下を2台または協力プレイヤーと確認してください。

- 本体で本アドオンのみ／LibGroupBroadcast併用を試し、ソロがどちらでも起動する。
- 「オプション」と「ログアウト」の間に「ゲームセンターPX」があり、配下から起動する。他のPX対応ゲームを消さない。
- 石の背景と全7色のブロック、ホールド・次ブロック、半透明の着地点が表示される。
- 画面端やキー案内が切れない。ポーズ・招待・終了メッセージが盤面の上に読める。
- 十字キー移動、長押し、左右回転、ホールド、両ドロップが反応する。画面を閉じて通常のESO操作に戻る。
- ソロの10ライン消去で速度が増す。終了後の再挑戦と再ログイン後の自己ベスト保存。
- 同じグループの2人で招待・承諾・開始。相手側がソロ中の招待、拒否、期限切れも確認。
- 2／3／4ライン消去によるおじゃま送信、受信、相殺。連続しても重複しない。
- 相手のトップアウト、降参、ほぼ同時終了、結果後の次の対戦。
- 通信切断、グループ離脱、戦闘開始、コントローラー切断で操作が残らない。
- PBsJankenおよび普段使用するアドオンとの併用。ID衝突時は /pbt debug の出力を確認。

一般公開前：LibGroupBroadcastのプロトコルIDを予約し、実機結果とバージョンを記録する。

## 1.1.0 追加確認（実機未確認）

- 雪の聖域が画面全体を覆い、ホールドと次ブロックがパネル内に収まる。
- 移動・回転・固定・ライン消去の効果音。長押しで過剰に重ならない。
- R1のBGM切り替え。ソロ一時停止・終了・対戦終了・コントローラー切断後に元のBGMに戻る。
- PS5で鳴るのはESO標準BGM。ブラウザの独自アレンジ曲とは別であること。

## 1.2.0 追加確認（実機未確認）

- メニューの20Gから直接起動。最初のブロックが既に接地し、横へ滑らせられる。
- 回転・ホールド・段差を降りた直後に浮遊しない。0.5秒の猶予で固定される。
- 通常モードのレベル20移行、通常／20G別の自己ベストと再挑戦。
- 両者1.2.0の対戦でライン消去とおじゃま段が従来どおり機能する。

## 1.3.0 追加確認（実機未確認）

- メニューからでも `/pbt` からでも盤面そのものが表示される。1.2.0ではボタン操作案内だけが出てウィンドウが出なかった。
- R1でBGMが切 → カード → 星座 → 決闘 → 終幕の順に変わり、表示名と実際に鳴る曲が一致する。
- 選んだBGMが再ログイン後も残る。1.1.0以前から更新した場合、BGMを切にしていた設定が引き継がれる。
- 盤面を閉じたあと、遊び始める前のBGMに戻る。
- アドオン一覧で期限切れ表示にならない（APIVersionに現行バージョンが含まれている）。

## 1.4.0 追加確認（実機未確認）

- R1でBGMが実際に切り替わる。1.3.0では表示名だけが変わり曲が変わらなかった。
- `/pbt debug` のBGM行で、要求値が `nil` でなく、現在値と一致し、所有が「あり」になっている。
- ライン消去が左から右へ払われて見える。コマ送りに見えるほど粗くない。
- 4ライン同時消去が金色で、通常消去の白と見分けられる。
- 高速落下中や20Gでも、演出のあいだに操作不能感や取りこぼしがない。

## 1.5.0 追加確認（実機未確認）

- 盤面が低いうちは雪がまばらで、積み上がるにつれて濃くなる。消せば弱まる。
- 雪がブロックや文字を読みにくくしない。特に一時停止・結果表示の重なり。
- ブロックの光沢が斜めに通り、点滅ではなく時折の煌めきに見える。
- 雪48片と光沢を出したままでも、PS5で操作が重くならない。落下やライン消去に遅延が出ないか。
- `assets/flake.dds` がPS5で実際に読み込まれている（読み込み失敗時は雪が四角く出る、または出ない）。

## 1.6.0 追加確認（実機未確認）

- メニュー選択後、画面が暗転してから盤面が出る。暗転がゲームパッドメニューごと覆っている。
- 暗転と盤面のあいだに通常のゲーム画面が一瞬も見えない（1.6.0で見えていた）。
- 暗転の長さが待たされる感じにならないか。`/pbt` と20Gからの起動も同様。
- 暗転中に最初のブロックが落ち始めていない。幕が明けてから動き出す。
- 暗転中に戦闘へ入った場合、盤面が出ずに幕だけ明ける。
- 対戦の招待を受けた側は暗転せず即座に出る。招待の応答が遅れない。
